# SHADOW DIRECTORY

A 5-page anime-inspired Student Directory mini project built using only HTML, CSS and JavaScript.

## Pages
- `index.html` — Solo Leveling / Shadow Monarch Student Directory
- `itachi.html` — Itachi profile
- `minato.html` — Minato profile
- `jiraiya.html` — Jiraiya profile
- `hinata.html` — Hinata profile

## JavaScript requirements covered
- Public JSON API: JSONPlaceholder Users API
- `async/await` + `fetch()`
- Error handling with `try/catch`
- `map()` for transforming API data and rendering
- `filter()` for search and city filtering
- Small functions for each responsibility
- Search by name/email
- City filter
- No results state
- Loading and error states
- Reset filters

## Run
Open `index.html` in a browser. For best results, use VS Code Live Server.
